Workflows in Practice

See decomposition and composition in real workflows

Document Decomposition

Pattern: Complex → Atomic → Synthesized

Take a PDF document, extract and split it into logical sections, process each section with specialized agents (summarizer, fact-checker, sentiment analyzer), then compile all analyses into a comprehensive report.

Use case: Legal document review, research paper analysis, contract summarization, regulatory compliance checks.

Multi-Agent Research Pipeline

Pattern: Sequential Composition

Start with a user topic, pass it to a research agent to gather data, send findings to a data analyst to identify patterns, have a content writer draft an article based on insights, then refine with an editor agent for final output.

Use case: Content creation, market research reports, competitive analysis, technical documentation.

Parallel Processing

Pattern: Decompose → Parallel → Converge

Input branches to multiple agents processing different aspects simultaneously (e.g., multiple data sources, different analytical perspectives, various content formats), then all outputs converge to a synthesis agent that creates a unified result.

Use case: Multi-source data analysis, A/B testing evaluation, comprehensive competitive research, cross-functional project planning.
