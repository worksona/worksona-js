▦ Visual Workflow Builder

What you'll learn: How to design complex AI workflows using the intuitive node-based interface, connect inputs to agents to outputs, and organize your workflow canvas.

1
Open the Canvas

Launch Worksona Studio. You'll see a blank canvas with a toolbar on the left containing different node types.

💡 Pro Tip

Use Cmd/Ctrl + Mouse Wheel to zoom. Middle mouse button or Space + Drag to pan around the canvas.

2
Add a Start Node

Click the "Start" button in the sidebar or drag a Start node onto the canvas. This is the entry point for your workflow.

  • Every workflow begins with a Start node
  • You can only have one Start node per workflow
  • The Start node triggers the workflow execution
3
Add Input Nodes

Click "User Input" or "File Input" to add data sources to your workflow.

📝 Example

User Input: For text prompts like "Write an article about AI"
File Input: For documents, images, or data files

4
Add Agent Nodes

Click "Agent" in the sidebar. A dialog opens where you select the agent type (e.g., Research Analyst, Content Writer, Data Analyst).

  • Choose the agent that matches your task
  • Select the AI model (GPT-4o, Claude 3.5, Gemini 1.5)
  • Set temperature (0-1, lower = focused, higher = creative)
  • Configure max tokens for response length
5
Connect Nodes

Drag from a node's output handle (right side) to another node's input handle (left side). Connections define data flow.

💡 Connection Rules

Data flows left-to-right. Each agent receives input from connected nodes and passes output to the next nodes.

6
Add an End Node

Click "End" to add the final node. Connect your last agent to the End node to complete the workflow.

7
Organize Your Layout

Drag nodes to arrange them clearly. Use the mini-map (bottom-right) to navigate large workflows.

  • Arrange nodes left-to-right following data flow
  • Group related nodes vertically
  • Leave space for future additions

◉ Multi-Agent Orchestration

What you'll learn: How to chain multiple AI agents together seamlessly, pass outputs between agents, and create sophisticated multi-step workflows.

1
Plan Your Agent Chain

Identify the sequence of tasks. Example: Research → Write → Edit → Generate Image

📝 Blog Article Workflow

Input (topic) → Research Analyst → Content Writer → Content Writer (editor role) → Image Generator → End

2
Add Your First Agent

Add a User Input node with your starting prompt, then add your first agent (e.g., Research Analyst).

  • Connect Start → User Input → Research Analyst
  • Configure the Research Analyst with GPT-4o
  • Set temperature to 0.3 for focused research
3
Chain the Second Agent

Add a Content Writer agent. Connect Research Analyst → Content Writer.

💡 Data Flow

The Content Writer automatically receives the Research Analyst's output as context. No manual copying needed!

4
Add Parallel Agents

You can split workflows! Connect one agent to multiple downstream agents for parallel processing.

📝 Parallel Processing

Content Writer → Image Generator (for blog header)
Content Writer → Marketing Agent (for social posts)
Both run simultaneously with the same article as input

5
Merge Outputs

Connect multiple agents to a single downstream node to combine their outputs.

  • The downstream agent receives all connected outputs
  • Use a "Content Writer" as a summarizer to combine results
  • Or connect directly to End node to see all outputs
6
Configure Each Agent Independently

Click any agent node to edit its settings. Each agent can use different models, temperatures, and prompts.

⚠️ Token Limits

Later agents in the chain receive accumulated context from all previous agents. Consider using higher max_tokens for agents deep in the chain.

7
Test Your Chain

Click the "Execute" button (play icon) to run your multi-agent workflow. Watch each agent complete in sequence.

⚡ Multi-Provider AI Support

What you'll learn: How to access GPT-4o, Claude 3.5 Sonnet, and Gemini 1.5 Pro, switch between providers and models, and optimize model selection for each agent.

1
Configure API Keys

Click the profile icon (top-right) → Settings. Add your API keys:

  • OpenAI API Key: For GPT-4o, GPT-4o-mini, GPT-3.5
  • Anthropic API Key: For Claude 3.5 Sonnet, Claude 3 Opus
  • Google API Key: For Gemini 1.5 Pro, Gemini 1.5 Flash
⚠️ Security

API keys are stored locally in your browser. They're never sent to our servers—only directly to OpenAI, Anthropic, and Google.

2
Select Model Per Agent

When adding or editing an agent, choose from the Model dropdown:

// OpenAI Models gpt-4o // Best overall, multimodal gpt-4o-mini // Fast and cost-effective // Anthropic Models claude-3-5-sonnet // Best reasoning, long context claude-3-opus // Most capable // Google Models gemini-1.5-pro // Long context (1M tokens) gemini-1.5-flash // Fastest responses
3
Match Models to Tasks

Different models excel at different tasks:

📝 Model Selection Guide

Research & Analysis: Claude 3.5 Sonnet (superior reasoning)
Creative Writing: GPT-4o (engaging, nuanced)
Long Documents: Gemini 1.5 Pro (1M token context)
Quick Tasks: GPT-4o-mini or Gemini Flash (fast, cheap)
Code Generation: Claude 3.5 Sonnet or GPT-4o

4
Mix Models in One Workflow

Use the best model for each agent:

  • Research Agent: Claude 3.5 Sonnet (deep analysis)
  • Writer Agent: GPT-4o (creative prose)
  • Editor Agent: GPT-4o-mini (grammar, quick)
  • Summary Agent: Gemini 1.5 Flash (fast final output)
💡 Cost Optimization

Use premium models (GPT-4o, Claude Sonnet) for critical reasoning tasks. Use mini/flash models for simple tasks like formatting or summaries.

5
Test Model Performance

Run the same workflow with different models to compare results. Duplicate an agent, change its model, and A/B test.

6
Handle Model Failures Gracefully

If a model is unavailable or times out, the workflow will show an error. You can:

  • Edit the agent and switch to a different model
  • Re-run just that agent (not the entire workflow)
  • Check your API key and quota

◈ Agent Tools & Extensions

What you'll learn: How agents can use file processors, image generators, and custom tools. How to build your own tools and extend agent capabilities infinitely.

1
Using File Input Nodes

Add a "File Input" node to process documents, images, CSVs, or code files.

  • Click "File Input" in the sidebar
  • Connect it to an agent
  • During execution, you'll be prompted to upload a file
  • The agent receives the file content as context
📝 Use Cases

• Analyze CSV data with Data Analyst
• Summarize PDF documents with Research Analyst
• Review code files with Code Reviewer
• Extract insights from images (with multimodal models)

2
Using Image Generation Nodes

Add an "Image Generation" node to create images with DALL-E or Stable Diffusion.

  • Click "Image Generation" in the sidebar
  • Connect an agent's output to it (the agent's output becomes the image prompt)
  • Or add a User Input for manual image prompts
  • Images are generated and displayed in the execution results
💡 Image Workflow Pattern

Content Writer → Image Generation: The writer creates an image prompt, then generates the image automatically.

3
Using Note Nodes for Context

Add "Note" nodes to inject static context, instructions, or reference material.

  • Click "Note" in the sidebar
  • Enter your reference text or guidelines
  • Connect the Note to agents that need this context
  • Notes are always included in agent prompts
📝 Note Uses

• Brand guidelines for marketing content
• Style guides for writers
• Data schemas for analysts
• API documentation for code agents

4
Using MCP Tool Nodes

Add "MCP Tool" nodes to extend agents with custom capabilities via the Model Context Protocol.

  • MCP tools provide agents with access to external APIs, databases, or custom functions
  • Examples: Web search, database queries, file system operations, API calls
  • Click "MCP Tool" in the sidebar and configure the tool
⚠️ Advanced Feature

MCP Tools require server configuration. See the MCP Integration docs for setup instructions.

5
Building Custom Agent Tools

You can create custom agent definitions with specialized capabilities:

  • Copy an agent JSON file from the agents/ directory
  • Modify the system prompt to define new behaviors
  • Specify tool access and capabilities
  • Save as a new agent type
{ "name": "custom-analyst", "description": "Your custom agent", "systemPrompt": "You are a specialized agent...", "temperature": 0.5, "tools": ["file_processor", "web_search"] }
6
Combining Multiple Tools

Create workflows where agents use multiple tools in sequence:

📝 Multi-Tool Workflow

File Input → Data Analyst (processes file) → Content Writer (writes report) → Image Generator (creates charts) → End

⬡ Atomic & Reasoning Agents

What you'll learn: How to combine simple atomic agents with complex reasoning agents, build emergent intelligence from composable parts, and create workflows that think.

1
Understanding Atomic Agents

Atomic agents perform single, focused tasks with no complex reasoning:

  • Format Converter: Transforms data from one format to another
  • Extractor: Pulls specific information from text
  • Validator: Checks data against rules
  • Summarizer: Condenses text to key points
📝 Atomic Agent Characteristics

• Single responsibility
• Low temperature (0.1-0.3) for consistency
• Fast, cheap models (GPT-4o-mini, Gemini Flash)
• Predictable, deterministic output

2
Understanding Reasoning Agents

Reasoning agents perform complex analysis, planning, and decision-making:

  • Research Analyst: Deep analysis and synthesis
  • Business Strategist: Strategic planning and recommendations
  • Legal Agent: Contract analysis and risk assessment
  • Financial Analyst: Market analysis and forecasting
📝 Reasoning Agent Characteristics

• Multi-step thinking
• Higher temperature (0.5-0.7) for creativity
• Premium models (Claude 3.5, GPT-4o)
• Nuanced, adaptive output

3
Composing Atomic Agents

Build complex behaviors from simple agents:

📝 Data Processing Pipeline

File Input → Validator (check format) → Extractor (pull fields) → Format Converter (to JSON) → Data Analyst (reasoning) → Content Writer (report)

Three atomic agents (validate, extract, convert) prepare data for the reasoning agent.

4
Reasoning Before and After Atomic Tasks

Use reasoning agents to plan, then atomic agents to execute, then reasoning agents to synthesize:

  • Plan: Business Strategist defines requirements
  • Execute: Atomic agents gather and process data
  • Synthesize: Financial Analyst creates final report
5
Creating Feedback Loops

Combine reasoning and atomic agents in iterative patterns:

📝 Iterative Refinement

Content Writer (draft) → Validator (check quality) → If issues → Content Writer (revise) → Validator (re-check)

Note: Currently requires manual iteration. Future versions will support automatic loops.

6
Building Emergent Intelligence

When atomic and reasoning agents work together, the system can:

  • Handle complex, multi-faceted problems
  • Maintain consistency while being creative
  • Scale to large data volumes
  • Adapt to changing requirements
💡 Design Pattern

Think of atomic agents as "hands" (doing specific tasks) and reasoning agents as "brain" (thinking, planning, judging).

▶ Real-Time Execution

What you'll learn: How to run workflows, watch live execution, view intermediate outputs, debug issues instantly, and monitor progress in real-time.

1
Start Workflow Execution

Click the "Execute" button (▶ play icon) in the top toolbar.

  • The workflow validates before starting
  • If validation fails, errors are shown on the canvas
  • If validation passes, execution begins immediately
⚠️ Required: API Keys

Ensure you've configured API keys in Settings before executing workflows.

2
Provide Input Data

If your workflow has User Input or File Input nodes, you'll be prompted:

  • User Input: Type or paste your text
  • File Input: Click "Upload" and select a file
  • After providing all inputs, execution starts
3
Watch Real-Time Progress

The execution modal shows live progress:

  • ✅ Green checkmark: Agent completed successfully
  • ⏳ Spinner: Agent currently executing
  • ⏸️ Gray: Agent waiting for dependencies
  • ❌ Red X: Agent failed with error
💡 Execution Order

Agents execute in topological order based on connections. Parallel branches run simultaneously.

4
View Intermediate Outputs

Click any completed agent in the execution modal to view its output:

  • See the full response from that agent
  • Check token usage and timing
  • Verify the agent did what you expected
  • Copy output for debugging
5
Debug Execution Issues

If an agent fails, click it to see the error:

  • API Key Error: Check your keys in Settings
  • Timeout: Agent took too long, try lower max_tokens
  • Invalid Prompt: Check agent input/connections
  • Rate Limit: API provider rate limited you, wait and retry
💡 Quick Fix

You can edit agent settings during execution failure, then click "Retry" to re-run just that agent.

6
View Final Results

When execution completes, the modal shows all outputs:

  • Scroll through each agent's result
  • Copy outputs to clipboard
  • Download results as JSON
  • View execution time and token counts
7
Access Execution History

Click the "History" button (clock icon) to view past executions:

  • See all previous runs with timestamps
  • Re-open any execution to view its results
  • Compare outputs across runs
  • Use history for debugging and optimization

⊡ Workflow Sharing

What you'll learn: How to auto-save workflows, export/import as JSON, share via URL, and track execution history.

1
Auto-Save with IndexedDB

Worksona Studio automatically saves your work to your browser's local storage:

  • Saves every 15 seconds after changes
  • No account or login required
  • Persists across browser sessions
  • Watch for the "✓ Saved" indicator
💡 Auto-Save Status

The save indicator appears in the top-right corner. Green = saved, Orange = saving, Red = error.

2
Manual Save

Force a save anytime with Cmd/Ctrl + S or click the save icon.

⚠️ Browser Storage Limits

IndexedDB has storage limits (~50-100MB). For large workflows with many executions, export to JSON periodically.

3
Export Workflow as JSON

Click the menu (☰) → "Export Workflow":

  • Downloads a .json file
  • Contains complete workflow definition
  • Includes all nodes, connections, and settings
  • Does NOT include execution history (for privacy)
📝 Use Cases for Export

• Backup important workflows
• Share workflows with team members
• Version control (commit to Git)
• Transfer between devices

4
Import Workflow from JSON

Click the menu (☰) → "Import Workflow":

  • Select a .json workflow file
  • The workflow loads onto your canvas
  • Replaces current workflow (save first!)
  • All agents and settings are restored
5
Share via URL

Click the "Share" button (🔗 icon) to generate a shareable link:

  • Uploads workflow to secure cloud storage
  • Generates a unique URL
  • Anyone with the link can import the workflow
  • Links expire after 30 days
⚠️ Shared Workflows Are Public

Don't include sensitive data, API keys, or confidential information in shared workflows.

6
View Execution History

Click the "History" button (🕐 clock icon):

  • See all workflow executions with timestamps
  • Click any execution to view its results
  • Compare outputs from different runs
  • Delete old executions to save space
7
Clear Canvas

Click the menu (☰) → "New Workflow" to start fresh:

  • Clears all nodes from canvas
  • Prompts to save current workflow first
  • Keeps execution history and settings

💬 AI Assistant (Natural Language Workflow Creation)

What you'll learn: How to use the AI chatbot to create and modify workflows using natural language, with no coding or technical knowledge required.

1
Open the AI Assistant

Click the "AI Assistant" button on the right edge of the canvas. The chat panel slides in.

💡 Keyboard Shortcut

Press Cmd/Ctrl + K to quickly toggle the AI Assistant panel.

2
Describe Your Workflow

Type a natural description of what you want to build. Be specific about:

  • The input (topic, data, file)
  • The steps/agents needed (research, write, analyze)
  • The output (article, report, images)
📝 Example Prompts

Simple: "Create a workflow that researches a topic and writes an article"

Detailed: "Build a blog post generator: start with a topic input, use a research agent to gather information, a writer to create the article, an editor to polish it, and two image generators for header and inline images. End with a summary."

Technical: "I need a data analysis pipeline: file input for CSV, data analyst to clean and analyze, then generate visualizations, and a business strategist to write executive summary."

3
Review the AI's Plan

The AI will show you what it plans to create:

  • List of nodes it will add
  • How they'll be connected
  • Which models it will use
  • Any settings or configurations

Review this plan. If it looks good, proceed. If not, provide feedback.

4
Apply the Workflow

Click "Apply Changes" in the chat. The AI instantly:

  • Adds all nodes to your canvas
  • Connects them properly
  • Configures agents with optimal settings
  • Positions nodes in a clear layout
💡 Watch the Magic

You'll see nodes appear and connect in real-time. The workflow is immediately ready to execute!

5
Modify the Workflow

Continue chatting to refine the workflow:

📝 Modification Examples

"Add a marketing agent to create social media posts"
"Change the research agent to use Claude instead of GPT"
"Remove the image generator"
"Connect the editor directly to the summary, skip the social posts"
"Add a file input at the beginning for document upload"

6
Iterative Refinement

The AI remembers your conversation and current workflow state:

  • Make changes incrementally
  • Test after each change
  • Ask the AI for suggestions: "How can I improve this?"
  • Request optimizations: "Make this faster and cheaper"
7
Load Existing Workflows

The AI can also help you work with existing workflows:

📝 Loading Commands

"Load my blog workflow"
"Show me all my saved workflows"
"Load the research template"
"Clear the canvas and start fresh"

8
AI Assistant Best Practices

Get the best results from the AI:

  • Be specific: More detail = better results
  • Iterate: Start simple, refine gradually
  • Ask questions: "What models should I use for research?"
  • Request explanations: "Why did you connect it that way?"
  • Test frequently: Execute workflows after AI changes to verify
⚠️ Review AI Changes

Always review what the AI created before executing. The AI is smart but can make mistakes.

9
Advanced: Context-Aware Suggestions

The AI understands your workflow and can suggest improvements:

📝 Ask for Help

"This workflow is slow, how can I speed it up?"
→ AI suggests using faster models or parallel processing

"I need better quality research output"
→ AI recommends Claude 3.5 Sonnet and increased max_tokens

"How do I add image generation?"
→ AI explains and offers to add Image Generation nodes
