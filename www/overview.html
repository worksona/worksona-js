Worksona.js Overview

AI Agent Management Library & API Server

What is Worksona.js?

Worksona.js is a powerful, single-file JavaScript library (2,241 lines, zero runtime dependencies) that provides sophisticated AI agent management across multiple LLM providers. It operates in two modes: as a direct JavaScript library or as a REST API server.

Quick Start

Installation

Install via npm:

npm install worksona-js

Basic Usage

Library mode:

const Worksona = require('worksona-js');

const worksona = new Worksona({
  openai: { apiKey: 'your-openai-key' }
});

await worksona.loadAgent({ id: 'assistant', ... });
const response = await worksona.chat('assistant', 'Hello!');

API Server mode:

node worksona-server.js

# Then make HTTP requests:
curl -X POST http://localhost:3000/api/query \
  -H "Content-Type: application/json" \
  -d '{"agent": "assistant", "query": "Hello!"}'
