What is AI Engineering with Worksona?

Build production-ready AI applications with multi-agent orchestration. Worksona.js provides a complete SDK for integrating GPT-4o, Claude, Gemini, and other frontier models into your applications with library or API modes.

Multi-Provider Support

Integrate OpenAI, Anthropic, Google, and more with a unified interface.

Dual-Mode Architecture

Use as a JavaScript library or deploy as a standalone API server.

Agent Orchestration

Build complex multi-agent workflows with delegation and state management.

Production Ready

Complete error handling, streaming responses, and comprehensive API reference.

Quick Start

1

Install Worksona.js

Choose library mode or API mode:

<script src="https://unpkg.com/worksona-js@latest/worksona.min.js"></script> node worksona-server.js # Then make API calls to http://localhost:3000/api

Or install via NPM:

npm install worksona-js
2

Configure Your Agent

Set up your first AI agent with provider credentials:

// Initialize with your API keys const worksona = new Worksona({ apiKeys: { openai: 'sk-...', anthropic: 'sk-ant-...', google: 'AIza...' } }); // Load an agent await worksona.loadAgent({ id: 'assistant', config: { provider: 'openai', model: 'gpt-4o', temperature: 0.7, systemPrompt: 'You are a helpful assistant.' } });

View full documentation

3

Start Building

Chat with your agent and build AI-powered features:

// Chat with agent const response = await worksona.chat('assistant', 'Hello!'); console.log(response.content); // Stream responses await worksona.chat('assistant', 'Tell me a story', { stream: true, onToken: (token) => console.log(token) }); // Multi-agent workflows await worksona.delegate('researcher', 'agent-1', 'Research AI trends'); const results = await worksona.getResults('agent-1');

Worksona.js Quick Reference

Library Mode - JavaScript

// Initialize Worksona const worksona = new Worksona({ apiKeys: { openai: 'sk-...', anthropic: 'sk-ant-...' } }); // Load an agent await worksona.loadAgent({ id: 'assistant', config: { provider: 'openai', model: 'gpt-4o', temperature: 0.7 } }); // Chat with agent const response = await worksona.chat('assistant', 'Hello!'); // Generate image const imageUrl = await worksona.generateImage('sunset over mountains', { size: '1024x1024', quality: 'hd' });

API Mode - HTTP Endpoints

// Load an agent POST http://localhost:3000/api/agents/load { "id": "assistant", "config": { "provider": "openai", "model": "gpt-4o", "temperature": 0.7 } } // Chat with agent POST http://localhost:3000/api/agents/assistant/chat { "message": "Hello!" } // Generate image POST http://localhost:3000/api/images/generate { "prompt": "sunset over mountains", "size": "1024x1024" }
