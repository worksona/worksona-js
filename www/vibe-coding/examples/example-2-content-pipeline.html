Multi-Agent Demo

Research → Write → Edit → Fact-Check workflow using Worksona API

🔍 How this works: This example uses raw API calls to the Worksona API server. Each agent specializes in a different task: researching, writing, editing, and fact-checking. The output of each step becomes the input for the next. Start the API server with node worksona-server.js
