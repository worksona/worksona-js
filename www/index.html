What is Worksona.js?

Dual-mode AI orchestration supporting GPT-5, Claude Opus 4.5, and o3 reasoning models

Library Mode
Import directly into your JavaScript/TypeScript application for zero-latency access to all features
API Mode
Deploy as a REST API server for language-agnostic access with simple HTTP requests
Multi-Provider
Unified interface for OpenAI, Anthropic, and Google with automatic fallback support
Latest Models
Full support for frontier models including GPT-5, Claude Opus 4.5, o3, and o3-mini
