About These Examples

This directory contains comprehensive examples demonstrating both Library Mode (direct JavaScript API) and API Mode (REST endpoints) of Worksona.js. Each example is fully functional and ready to use.

Quick Start: Open any HTML file directly in your browser, or run the Node.js demos with node dual-mode-demo.js

Library Mode vs API Mode

Library Mode (Direct JavaScript)

  • Zero network latency
  • Direct access to all features
  • JavaScript/TypeScript apps
  • Browser extensions
  • Electron apps
  • Real-time event monitoring

API Mode (REST Endpoints)

  • Language agnostic (Python, Ruby, PHP, Java)
  • Simple HTTP requests
  • Webhook support
  • File upload capabilities
  • External integrations
  • Mobile app backends

Getting Started

For Browser Demos:

1. Open dual-mode-demo.html or frontier-models-demo.html in your browser

2. Enter your API keys in the interface

3. Start testing!

For Node.js Examples:

1. Set environment variables: export OPENAI_API_KEY="sk-..."

2. For API mode, start server: node worksona-server.js

3. Run the demo: node examples/dual-mode-demo.js
