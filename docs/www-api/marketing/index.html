How It Works

Get started in three simple steps

1

Install or Deploy

# As Library
npm install worksona-js

# As API Server
docker run -p 3000:3000 \
  worksona/api-server
2

Configure Agents

const agent = await worksona.loadAgent({
  id: 'support-bot',
  config: {
    provider: 'openai',
    model: 'gpt-5'
  }
});
3

Start Building

const response = await worksona.chat(
  'support-bot',
  'How can I help you today?'
);

console.log(response);
