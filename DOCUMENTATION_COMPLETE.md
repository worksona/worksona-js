## 🌐 Deployment

### Local Development
1. Clone repository
2. Install dependencies: `npm install`
3. Start API server: `node worksona-server.js`
4. Open `/docs/index.html` in browser
5. Navigate between demos

### Production Deployment
- Serve `/docs` and `/marketing` as static files
- Ensure API server accessible at configured URL
- Configure CORS if needed
- Set environment variables for API keys
- Use CDN for Prism.js, Mermaid, Swagger UI

### Required URLs
- Prism.js: `https://cdnjs.cloudflare.com/ajax/libs/prism/1.29.0/`
- Mermaid: `https://cdn.jsdelivr.net/npm/mermaid@10/`
- Swagger UI: `https://unpkg.com/swagger-ui-dist@5.10.0/`
